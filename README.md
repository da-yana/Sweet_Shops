# sweetshops
Добро пожаловать в репозиторий проекта кондитерской "SweetShops".
Этот сайт создан для того, чтобы пользователи не смогли отказать своим сладким желаниям. Здесь можно посмотреть, какие десерты есть в нашем сладком мире, узнать их цену, а также связаться с нами для заказа.

## Функицонал
1. Презентация авторских десертов.
2. Галерея с работами.
3. Информация об ингридиентах и составе.
4. Контакты для оформления заказа или обратной связи.
